# Moved — the live inventory is `admin/REDESIGN-STATUS.md`

The handoff shipped a copy of the screen inventory. It is deliberately not kept
here, because two copies of a status table are two answers to "is this done
yet", and the one nobody edits is the one that gets read. This copy was already
behind the live one when the archive was handed over — it still had blocked
dates as `pattern`, and both `/youth` rows as screens rather than redirects.

**The inventory that is maintained is [`admin/REDESIGN-STATUS.md`](../admin/REDESIGN-STATUS.md).**
Task 0 names that path as its deliverable, so that is the one that is real.

Everything else in this directory — `FIXES.md`, `README.md`,
`IMPLEMENTATION-PHASES.md`, `screens/`, `screenshots/` — is the designer's, and
is the source of truth for what a screen should look like. Only the status
table moved.
